Standpoint Core models perspectives. But modeling isn't enough - systems need to *act* on that understanding.

Enter: Standpoint Mesh.

The Mesh is the collaboration layer that sits on top of Core. While Core answers "what does this situation mean from each perspective?", Mesh enables "how do we coordinate action given those different perspectives?"

Key principles emerging:
- Boundaries matter. Not everything should be shared with everyone.
- Context must be preserved across handoffs.
- Each participant's concerns must be respected, not just acknowledged.

The two products are starting to feel like a coherent whole. Core provides understanding, Mesh enables action.

More details as the architecture firms up.
